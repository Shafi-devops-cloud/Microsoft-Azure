Microsoft Azure Infrastructure as Code (IaC) & DevOps Hub

Welcome to the Microsoft Azure Infrastructure & CI/CD Hub. This repository serves as a centralized, production-ready repository for provisioning Azure Cloud Infrastructure using Terraform and automating software & infrastructure delivery using Azure DevOps Pipelines (azure-pipelines.yml).

It contains end-to-end architectures, Terraform modules, and CI/CD workflows covering Platform as a Service (PaaS), Serverless, Private Networking, and Security Hardening on Microsoft Azure.
